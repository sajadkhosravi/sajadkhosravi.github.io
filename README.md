# Sajad Khosravi - CV Website

This is my personal CV website built with Hugo and the cv-one theme.

## Features

- ✅ Responsive design with dark theme
- ✅ Configurable sections via YAML
- ✅ Research interest icons
- ✅ Social links configuration
- ✅ Download CV functionality
- ✅ Mobile-friendly navigation
- ✅ Print-friendly CSS

## Deployment

This site is automatically deployed to GitHub Pages using GitHub Actions.

- **Live Site**: https://sajadkhosravi.github.io/
- **Repository**: https://github.com/sajadkhosravi/sajadkhosravi.github.io

## Local Development

```bash
# Install Hugo (if not already installed)
# macOS: brew install hugo
# Linux: See https://gohugo.io/installation/

# Clone the repository
git clone https://github.com/sajadkhosravi/sajadkhosravi.github.io.git
cd sajadkhosravi.github.io

# Run the development server
hugo server --buildDrafts --buildFuture

# Open http://localhost:1313 in your browser
```

## Configuration

Edit `data/cv.yaml` to update your personal information. Comment out any fields you want to hide from the website.

Edit `hugo.toml` to configure site settings, social links, and section visibility.
